# SUB-TASK 1: INVESTIGATING GITHUB AND GITLAB

## 1. GitHub

GitHub is a web-based platform used by software developers to store, manage, share and collaborate on software projects. It uses Git for version control and allows developers to work together on code.

### Three key features of GitHub

1. **Repositories**
   A repository is a storage location for a project's files, source code and revision history. Developers can use repositories to manage and collaborate on their projects.

2. **Pull Requests and Code Review**
   Pull requests allow developers to propose changes to a project. Other team members can review the code, comment on changes and approve the changes before they are merged.

3. **GitHub Actions**
   GitHub Actions is an automation and CI/CD system. It can automatically build, test and deploy software when certain events occur in a repository.

### Other GitHub features

* GitHub Codespaces
* GitHub Copilot
* GitHub Discussions
* GitHub Packages
* GitHub Marketplace
* Code search
* Protected branches
* APIs and webhooks

---

## 2. GitLab

GitLab is a DevOps and software development platform that provides tools for planning, creating, testing, securing and deploying software. It provides source-code management together with built-in CI/CD and other DevOps tools.

### Three key features of GitLab

1. **Merge Requests**
   Merge requests allow developers to submit code changes for review. Team members can discuss the changes, review code and check CI/CD results before merging.

2. **Built-in CI/CD**
   GitLab provides integrated continuous integration and continuous delivery tools. Developers can automatically test, build and deploy applications using pipelines.

3. **Issue Boards**
   GitLab issue boards provide a visual way to manage and track work. Issues can be organised into lists and used for workflows such as Kanban and Scrum.

### Other GitLab features

* Source-code repositories
* Issues and project planning
* Code review
* Package Registry
* Container Registry
* Security testing
* Deployment management
* Feature flags
* Vulnerability management

# 3. Licensing

The main difference in licensing is that **GitLab's core Community Edition is open source under the MIT License**, while GitHub's platform and many of its products are proprietary services. GitHub does, however, host open-source projects and supports many different open-source licenses for repositories. GitHub's own applications can also contain open-source components under their respective licenses.

### GitHub licensing

GitHub itself is a hosted service and its products are not simply released as one open-source project. However, developers can place their own open-source software on GitHub and choose an appropriate open-source license for their repositories.

### GitLab licensing

GitLab Community Edition (CE) is licensed under the **MIT License**, while GitLab Enterprise Edition (EE) has additional restrictions under the GitLab Enterprise Edition license.

### Core distinction

**GitHub:** Mainly a proprietary hosted platform that supports hosting open-source projects.

**GitLab:** Provides an open-source Community Edition under the MIT License, while also offering additional proprietary Enterprise features.

# 5. Features Unique to GitHub

The following are examples of features that distinguish GitHub from GitLab:

### 1. GitHub Codespaces

GitHub Codespaces provides cloud-hosted development environments. Developers can open a configured development environment from a browser or connect to it using supported IDEs.

### 2. GitHub Marketplace

GitHub Marketplace provides applications and Actions that can be added to GitHub workflows to extend the functionality of repositories and development processes.

### 3. GitHub Copilot integration

GitHub provides GitHub Copilot features for AI-assisted software development, including code suggestions and coding assistance.

# 6. Features Unique to GitLab

### 1. Built-in DevSecOps platform

GitLab is designed as a single platform covering many stages of the software development lifecycle, including planning, source-code management, CI/CD, security, package management and deployment.

### 2. Integrated Container Registry

GitLab provides an integrated Container Registry where projects can store and manage container images. It can also be integrated directly with GitLab CI/CD pipelines.

### 3. GitLab Issue Boards

GitLab provides visual issue boards that can be used to organise tasks and support project-management methods such as Kanban and Scrum.

# 8. Similarities

GitHub and GitLab are similar because:

1. Both use **Git version control**.
2. Both provide **repositories** for storing source code.
3. Both support **branches and merging**.
4. Both provide **code review**.
5. Both provide **issue/project management tools**.
6. Both support **CI/CD automation**.
7. Both allow developers to collaborate on software projects.

---

# 9. Differences

The major differences are:

1. **Licensing:** GitLab Community Edition is MIT-licensed, while GitHub's platform is primarily a proprietary hosted service.

2. **CI/CD:** GitLab has CI/CD built directly into its platform, while GitHub uses GitHub Actions for workflow automation.

3. **Development approach:** GitHub is particularly well known for code hosting and developer collaboration, while GitLab focuses on providing a broader single application covering the software development and DevSecOps lifecycle.

4. **Terminology:** GitHub uses **Pull Requests**, whereas GitLab uses **Merge Requests**.

5. **Project management:** GitLab provides integrated Issue Boards for workflows such as Kanban and Scrum.

---

# 10. Conclusion

GitHub and GitLab are both powerful platforms for software development and collaboration. They both provide Git repositories, version control, code review, issue tracking and automation tools. GitHub is widely used for hosting and collaborating on software projects and provides services such as GitHub Actions, Codespaces and Marketplace. GitLab provides a broader integrated DevOps and DevSecOps platform with features such as built-in CI/CD, Issue Boards, security tools and an integrated Container Registry.

The most important licensing difference is that GitLab Community Edition is released under the MIT License, while GitHub's main platform is proprietary even though it supports open-source software and hosts projects using open-source licenses. Therefore, both platforms are useful, but GitLab may be more suitable for organisations wanting an open-source core and an integrated DevOps platform, while GitHub is particularly strong for developer collaboration and its large ecosystem.
